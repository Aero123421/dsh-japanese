# 日本語言語パック

公式DeepSeek HarnessのLocale APIに日本語辞書を登録します。設定の一般画面で「日本語」を選択してください。

Noto Sans JPをパッケージ内に同梱し、日本語のUIと会話本文に使用します。フォントのインストールや実行時の外部ダウンロードは不要です。利用者が指定したフォントは優先します。システムプロンプトは変更しません。

対応確認の対象は公式 `0.2.1-alpha.2` のソースです。Electron独自の案内画面、文書プレビュー、ターミナルのフォント設定は対象外です。

フォント提供元：[@fontsource-variable/noto-sans-jp](https://www.npmjs.com/package/@fontsource-variable/noto-sans-jp)、[Noto Sans JP](https://fonts.google.com/noto/specimen/Noto+Sans+JP)。同梱ファイル`dist/Noto-Sans-JP-OFL.txt`にSIL Open Font Licenseを記載しています。
