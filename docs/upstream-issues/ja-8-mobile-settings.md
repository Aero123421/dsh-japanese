# 幅 390px で設定の項目列が本文と重なる

対象: DeepSeek Harness `0.2.1-rc.2`（`687f282e8625c6b8d11ff58211a90524be2e4317`）

## 現象

設定ダイアログの幅が約 390px のとき、左の項目列が固定幅のまま本文の上に残ります。項目名を短くしても、列自体が本文の領域へ被さります。日本語・英語・中国語で同じ配置です。

## 期待

狭い幅では項目列が本文の上に乗らず、項目を選ぶと本文だけが表示されるか、列が本文の幅まで縮むこと。横スクロールで本文が隠れないこと。

## 再現の目安

ブラウザの幅を 390px にして、設定を開く。
