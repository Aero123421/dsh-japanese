# トーストの最終行に1文字だけ残る

対象: DeepSeek Harness `0.2.1-rc.2`（`687f282e8625c6b8d11ff58211a90524be2e4317`）

## 現象

ワークスペースを作れなかったときのトーストなど、1文の通知が狭い幅で折り返されます。日本語では末尾の「い。」だけが次の行に残ることがあります。

英語の文も同じトースト幅です。改行位置は文の長さとトーストの最大幅で決まり、言語パック側の訳を少し短くしても、別の文で同じ形になります。

## 期待

トーストの本文は、最終行に1文字だけが残らない幅か、折り返しの余白を持って表示されること。

## 再現の目安

日本語表示で、既定のワークスペース作成に失敗する操作を行い、画面上部のトーストを見る。
