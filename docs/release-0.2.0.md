# 0.2.0 更新内容

設定に「日本語パック」を追加し、実行版と正式Releaseの更新確認・明示的な更新操作を表示します。更新画面には日本語・英語の文言とDSHのUI部品を使用します。

辞書・フォント登録は独立して動作し、slots・connection・plugin managerがない構成でも日本語化を停止しません。表示言語、ユーザー指定のテキスト・コード用フォント、他の辞書やstyle、モデルへの指示は変更しません。

更新は固定repositoryのタグまたは検証済みtgzをDSHのplugin managerに渡し、配布経路、版固定、bundleのON/OFFを維持します。通信切断後は導入を再送せず、保存した操作IDと結果・導入版・実行版を照合します。失敗、取消、上書き、再起動待ち、実行版確認、結果不明を区別します。

今回の検証コマンドと対象はPRに記録します。実Release間の更新は公開後の確認が必要です。Windows・macOS実機、Electron、Glass UIとの実併用は未検証です。
