## 検証と再現

Node 24.19.0、Chromium 154。最終差分で以下が成功しました。

```sh
npm run build
DSH_PUBLISHED_LOCALE_CLIENT=/path/to/dsh-client-locale/lib/client.js npm test
npm run typecheck
DSH_TEST_CHROMIUM=/path/to/chromium npm run test:browser
npm run sync:contracts
npm run pack:plugin
```

alphaの実配布Localeを使う55/55単体、rc.4の実配布Locale回帰1/1、typecheck/build、公式rc.2ソースのbrowser fixture16状態、pack成功。再buildしたdistは検証済み全file hashと一致しました。契約は59名前空間・2672キー、rc.2固定fixtureは再生成して差分なしです。

開始mainのdistにalpha回帰を適用すると `locale namespace "pluginManager" already has locale "ja"` を再現し、修正後は本体辞書を保持したまま2回のON/OFFが成功しました。実配布Localeコードと内蔵辞書をVMで使用し、DOM・設定transport・slotは代替です。browser fixtureは公式Locale/rendererを使い、更新RPCは代替です。外部Localeファイルを指定しない通常の `npm test` はその1テストだけskipします。
