# 0.2.2 更新内容

自己更新で旧版を外したあと新しい版の導入が失敗・取消になった場合に、以前の版を同じ導入元と有効状態で入れ直すようにしました（Issue #7）。入れ直しにも失敗したときは、プラグインが外れている可能性と、設定の「プラグイン」→「プラグインを追加」または `dsh plugin --profile web add -w github:Aero123421/dsh-japanese` で入れ直す方法を表示します。

あわせて、DSH 0.2.x の peer 範囲（`>=0.2.1-alpha.2 <0.3.0-0`）と HMR が有効な DSH での再導入に追従しました（旧ドラフト PR #6 の内容を #8 に取り込み）。
