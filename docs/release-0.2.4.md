## 0.2.4

- DSH本体や他の提供元が日本語を所有する場合はその辞書を尊重し、名前空間の重複登録を避けます。提供元が外れた場合はパックの辞書を登録し、所有を失うと解除します。フォントと更新画面は引き続き利用できます。
- DSH 0.2.1-rc.4/rc.5の追加8キーを翻訳しました。辞書は59名前空間・2672キーです。
- 更新画面の導入・有効化・削除の段階名と、別の更新が進行中の理由を日英で表示します。
- 更新候補のDSH互換判定を本体の `engines.dsh` 優先規則に合わせました。

検証はNode.jsのテスト、型検査、ビルド再現、公式Locale実配布（rc.5・0.2.2-alpha.2）、Chromiumのテスト画面で行いました。実Locale検証のDOM・設定通信・UI slotは代替です。実際の更新サービス、Windows・macOSやElectronでの今回の配布物の新規導入は未検証です。

### 既知の注意

- exportダイアログの英語表示や、幅390pxで権限の説明が切れる問題は未確認です。
- 以前のリリースで、pnpm 12を使ったプラグイン追加・更新時に公開後24時間未満の依存による `ERR_PNPM_MINIMUM_RELEASE_AGE_VIOLATION` が発生すると、DSHが同じプロファイルの `node_modules` を復旧できない場合が報告されています。追加・更新にはpnpm 10を使い、問題発生時はpnpm 10で `dsh plugin --profile web install` を実行してください。最新DSHでの解消状況は未確認です。
